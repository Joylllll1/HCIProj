# ADR-002：匿名映射逻辑独立为单独服务

## 状态
已接受

## 背景
匿名性是核心特性和关键约束。系统需实现帖子级匿名：同一用户在不同帖子显示不同匿名 ID，同时管理员需能追溯真实身份。将匿名逻辑与业务逻辑混合会导致代码耦合、难以维护和审计、增加隐私泄露风险。

## 决策
将匿名映射逻辑独立为 `anonymousService.js`，所有匿名 ID 生成、验证、追溯操作必须通过该服务。

## 理由
1. 职责单一——匿名映射是独立业务领域
2. 安全性——独立服务便于权限控制和安全审计
3. 可维护性——匿名逻辑集中，修改不影响其他模块
4. 可测试性——独立服务便于编写单元测试
5. 可审计性——所有匿名操作集中，便于审计和追溯

## 后果
- 正面：提高安全性和隐私保护、降低代码耦合度
- 负面：增加服务层调用开销、需设计清晰的服务接口
- 风险：映射数据加密存储、防止匿名 ID 被破解或关联、管理员追溯的权限控制
