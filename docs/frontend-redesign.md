# 南大树洞前端改版说明

此项目用于人机交互课程作业。用户指定 [Treehole Art](https://arthals.ink/blog/treehole-art) 为参考；本次借鉴内容优先、三栏阅读、就地发布和讨论的交互方式，保留南大品牌、匿名身份算法及现有功能。

## 设计依据与实际改动

| 依据 | 原有问题 | 当前实现 |
| --- | --- | --- |
| [Nielsen：审美与简约](https://www.nngroup.com/articles/ten-usability-heuristics/) | 欢迎语、轮播、装饰和说明占用首屏 | 首页直接呈现发布表单和连续信息流；减少阴影、头像和重复时间，运势默认折叠 |
| [Nielsen：用户控制、识别优先](https://www.nngroup.com/articles/ten-usability-heuristics/) | 看评论必须跳页，返回后排序和分页重置 | 帖子下展开讨论；支持只看洞主、按评论者筛选；独立详情仍可访问；返回保留排序、已加载页、展开状态和阅读位置 |
| [Nielsen：状态可见与错误恢复](https://www.nngroup.com/articles/ten-usability-heuristics/) | 评论发出后立即清空，失败会丢失文字；请求失败可能表现为空列表 | 评论和回复等待成功才清空；发送中禁用重复操作，失败保留文字与图片；列表加载、失败和空态分开，失败保留上次结果并提供重试 |
| [Nielsen：一致性、用户控制](https://www.nngroup.com/articles/ten-usability-heuristics/) | 输入即搜索；话题其实是模糊关键词 | 搜索确认后生效；最近 8 条搜索和清空记录；⌘/Ctrl K 聚焦；后端以 `tag` 参数精确筛选标签，可与关键词组合 |
| [WCAG：点击目标](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum) | 图标小、部分交互缺少按钮语义 | 使用原生按钮、下拉框、可访问名称、选中状态和可见焦点；正文与操作分开；手机筛选改为下拉框 |
| [WCAG：状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages) | 等待、失败及恢复操作不明确 | 加载使用 status，错误使用 alert，发送按钮显示发送中 |
| 不同阅读场景 | 只有浅色，夜间阅读缺少选择 | 浅色、深色、跟随系统；本机保存偏好；语义颜色覆盖帖子、表单、收藏、设置及共享弹层 |

这些改动是依据启发式和任务走查作出的设计判断。没有进行真实用户实验，不能将其表述为已经测得的效率提升，也不宣称整站已通过 WCAG 认证。

## 主要操作路径

- 阅读与回应：首页 → 展开评论 → 筛选洞主或评论者 → 回复；也可以打开完整树洞并返回。
- 发布：首页输入文字、可选标题、话题和图片 → 发布；需要多图、心情或草稿时进入完整编辑器，已输入内容随之带入。
- 寻找：输入关键词 → 按 Enter 或搜索按钮确认；选择话题可进一步筛选；清除筛选恢复全部内容。
- 回访：收藏 → 选择收藏夹 → 首页右侧直接打开该收藏夹。
- 长列表：滚动接近底部自动加载下一页，同时保留手动加载和失败重试入口。

## 实现边界

`docs/design/product-brief.md`、`docs/design/ui-spec.md` 记录产品与视觉约定，`frontend/src/styles/community.css` 记录应用样式。`Discussion` 与 `ResponseInput` 在详情和信息流复用，避免两套提交行为。

后端仅为列表增加可选的精确 `tag` 参数，与现有关键词、排序和分页组合使用。真实帖子仍使用现有 ID；分享功能复制真实详情链接，没有伪造数字洞号。鉴权和匿名映射规则沿用原实现。

本轮借鉴参考的阅读与互动模式，没有复刻其所有功能。数字洞号、引用帖子语法、排除词搜索、屏蔽词、实名身份标签和评论浮层模式不属于本轮新增能力。

快捷发布和回复草稿只在当前应用会话内保留，刷新后清空；需要长期保存时使用完整编辑器的草稿箱。搜索历史和主题偏好保存在此设备，可分别清空或修改。退出或切换账号会清空当前内存中的快速发布和评论草稿。
