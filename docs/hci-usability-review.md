# 人机交互任务走查与修正

日期：2026-10-23。对象：南大树洞的普通用户前端，含电脑与手机。此轮从“删除一篇草稿要先进入批量管理”的反馈出发，按阅读、表达、整理和账号操作检查流程，不以视觉统一代替交互验收。

## 采用的依据

- [Nielsen 十项可用性启发式，NN/g](https://www.nngroup.com/articles/ten-usability-heuristics/)：重点采用状态可见、用户控制、错误预防、识别优先和错误恢复。这些是评审原则，不是已完成用户研究的证明。
- [WCAG 2.2，点击目标最小尺寸的说明，W3C](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：图标的视觉尺寸与点击范围分别处理。次要操作保持细小图标和文字，保留至少 24 CSS px 的目标或足够间距；本轮草稿动作实际采用 32px/36px 高度。
- [Treehole Art，Arthals](https://arthals.ink/blog/treehole-art)：参考连续阅读、深浅主题、多端适配及就近管理内容的模式。保留南大树洞的业务和身份，不复制对方品牌或源代码。

## 发现与处理

P1 表示可能丢失内容或漏发内容；P2 表示明显增加操作成本、造成误解或妨碍恢复。分级为本次代码与任务走查判断，未虚构用户实验数据。

| 问题 | 级别 | 对应原则 | 实际改动 |
| --- | --- | --- | --- |
| 删除一篇草稿必须进入批量模式 | P2 | 识别优先、效率 | 每行直接提供“继续编辑”“删除”，手机保留文字；批量模式只处理多选 |
| 草稿删除失败只有短暂提示，删除后原按钮消失导致焦点无处可去 | P2 | 错误恢复、用户控制 | 确认中说明具体草稿；就地错误和重试；请求中防重复；成功后聚焦剩余条目或空态入口 |
| 草稿尚未加载时可输入，加载完成覆盖输入 | P1 | 状态可见、错误预防 | 加载时锁住编辑区，失败保留页面并显示重试 |
| 保存期间继续输入被保存响应覆盖，首次保存还会触发 App 再次加载 | P1 | 错误预防 | 保存快照与当前内容分开；旧响应不替换新输入；编辑器创建的草稿 ID 不重复加载 |
| 图片还在处理时可发布，保存与发布可能并发 | P1 | 状态可见、错误预防 | 预留图片容量、展示处理状态、序列化保存和发布；完成后再允许提交 |
| 发布失败后离开保护提前解除；旧编辑器异步完成可能改变已经离开的地址 | P1 | 用户控制、错误恢复 | 成功前持续保留保护；已卸载编辑器不再改 URL、共享草稿 ID 或跳转 |
| 评论处理图片时输入的新文字可能恢复成旧版本，跨页面请求还可能清空更新的草稿 | P1 | 错误预防、连续性 | 同一讨论共用草稿和处理中状态；操作令牌确认归属；发送仅清理对应版本；图片合并最新文字；切换账号使旧操作失效 |
| 个人空间的收藏页隐藏“新建收藏夹” | P2 | 一致性、识别优先 | 紧凑视图保留新建入口；管理操作按收藏夹命名，键盘可展开、退出并返回焦点 |
| 收藏夹创建/改名可重复提交，删除使用另一套系统确认框 | P2 | 一致性、错误预防 | 统一确认，说明内容仍在“全部”；表单保留失败输入和重试，处理中禁用重复操作 |
| 手机从收藏/喜爱打开帖子再返回会跳回“我的帖子” | P2 | 用户控制、降低记忆负担 | 当前个人页选项保存在应用会话中，回退恢复 |
| 喜爱加载失败无重试，个人帖子/详情删除失败缺少就地反馈 | P2 | 错误恢复 | 明确失败和空态；补重试；删除保留确认及准确对象，等待成功再关闭 |
| 活动列表请求失败显示成空列表，活动申请能重复提交或丢掉未读完的海报 | P1/P2 | 状态可见、错误恢复 | 分开记录公共/个人列表错误，保留旧结果并重试；申请和海报读取有保护；关闭表单保留本页输入 |
| 更换邮箱后旧验证码仍留着，倒计时阻止向新邮箱发码 | P2 | 系统匹配、错误预防 | 验证码绑定已发送地址；变更地址清空验证码和倒计时；显示接收邮箱；发送和验证互斥 |
| 弹窗全部按钮禁用后、失败重新启用时焦点可能逃到背景 | P2 | 用户控制、键盘可用 | 面板在等待时可接收焦点；忽略禁用 fieldset；恢复后 Tab/Shift+Tab 回到正确按钮 |

## 行为取舍

单条删除采用“直接入口 → 确认”两步。破坏性动作不依赖悬停，图标不放大；确认可用 Escape 取消，默认先聚焦保留按钮。批量删除仍保留，因为多条整理是另一项任务。

本轮使用已有的 `DELETE /api/drafts/:id` 和批量删除接口，后端已经按所有者校验，无需为增加入口新增接口。标题不能单独保存为草稿，页面现在提前说明这一现有后端限制。

活动申请关闭后只在当前公告页面暂存，不是服务端草稿；离开或刷新公告页面会清空。帖子草稿箱是长期保存入口。评论草稿、个人页选项和异步状态只在当前应用会话内保留，退出或切换账号清空评论内容与操作。

## 验证与边界

具体执行结果随最终验收补充。验证使用隔离演示 API 与受控失败、延迟响应；不写真实账号或数据库，不发送真实验证码。

这是启发式走查和任务回归，不是整站 WCAG 认证，也不能替代真实用户测试。后台审核、真实邮件投递、AI 服务及生产数据库不在本轮端到端验收范围内。
