## Why

目前公告页面使用静态假数据展示，无法展示真实通过审核的校园活动。用户无法浏览学校最新的讲座、比赛、招聘会等活动信息，也无法提交自己的活动申请。为了完善校园信息流通，需要实现完整的活动墙功能，让用户可以查看、搜索、筛选活动，并提交自己的活动申请。

## What Changes

- **活动墙展示**：连接 AnnouncementsPage 到后端 API，展示所有已通过审核的活动
- **往期活动区域**：自动将已结束的活动折叠到"往期活动"区域
- **发布活动**：用户可提交活动申请，进入待审核状态
- **我的申请 Tab**：在公告页面增加"我的申请"标签页，查看自己提交的活动状态
- **分类筛选**：保留现有的活动类型筛选功能

## 非目标（明确不做）

- 首页轮播展示活动（后续迭代）
- 新活动上线通知推送（等待通知系统）
- 手动归档功能（过期自动处理）
- 活动报名/收藏/评论功能

## Capabilities

### New Capabilities
- `event-wall`: 活动墙展示功能，包括活动列表、分类筛选、往期活动、我的申请

### Modified Capabilities
- 无（公告审核功能已在 add-event-audit 中完成）

## Impact

- **前端页面**: AnnouncementsPage 需要重写，连接真实 API
- **后端**: 复用已有的 Event 模型和 API（已审核通过的活动查询）
- **数据库**: 复用现有 events 集合
- **用户交互**: 新增活动发布表单、我的申请列表
