# 前端阅读与交互体验优化

状态：代码已实现，最终本地验收记录见 `docs/frontend-redesign.md`。

## 目标与依据

用户指定 [Treehole Art](https://arthals.ink/blog/treehole-art) 为视觉和交互参考，并要求结合人机交互原则继续优化，可适当修改后端。保留南大身份和既有业务，改善内容层级、连续阅读、响应式布局和键盘操作。

设计依据：[Nielsen 十项启发式](https://www.nngroup.com/articles/ten-usability-heuristics/)、[WCAG 点击目标](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)、[状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages)。重点为状态可见、用户控制、识别优先、错误恢复和渐进展开。

## 行为要求

1. 首页首屏直接呈现紧凑的真实发布表单和连续帖子流；不显示欢迎轮播、营销介绍或大装饰区。
2. 快捷发布支持文字、可选标题、话题和图片；可带入完整编辑器继续编辑和使用草稿功能。
3. 帖子下可展开讨论，支持只看洞主和按评论者筛选；独立详情链接、既有点赞、收藏、举报和删除能力继续可用。
4. 评论和回复成功才清空；失败保留文字和图片并可重试；发送中阻止重复提交。展开状态和评论草稿在当前会话内往返详情时保留。
5. 返回信息流保留排序、已加载分页和阅读位置。滚动接近底部自动加载，并保留手动入口和失败重试。
6. 加载失败、正在加载和真实空列表明确区分；失败保留上次结果，不能把失败的排序标为成功。
7. 搜索仅明确提交后生效，最近 8 条搜索可复用或清空，支持 ⌘/Ctrl K 聚焦。话题独立于模糊搜索，使用后端精确标签筛选，可与关键词组合。
8. 右侧显示真实收藏夹和数量，可打开所选收藏夹；手机使用单行话题下拉，保留导航与发布入口。
9. 提供浅色、深色、跟随系统主题，刷新后保留偏好；核心页面、表单、焦点和反馈可读。
10. 演示模式明确标注、隔离 API 写操作、刷新可重置；生产构建不包含演示鉴权和示例数据。

## 实现边界

借鉴参考的阅读和互动模式，不要求复制其所有业务。保留现有帖子 ID、鉴权与匿名机制；新增分享动作复制真实详情链接。本轮不新增数字洞号、引用语法、排除搜索、屏蔽词、实名标签或评论浮层。浏览器走查使用隔离演示 API，真实账号、邮件、AI 和生产数据库未做端到端验收；不宣称已完成用户实验或整站 WCAG 认证。

- 顶栏和管理顶栏使用太阳/月亮按钮切换深浅色；设置页保留跟随系统选项，偏好仍持久化并可通过键盘操作。
- 验证手机/桌面实际截图、删除确认、深浅切换及系统偏好，运行前端 lint、测试与构建。

- 入口页沿用社区的细边框、紧凑内容列表和小图标，改善字号、留白和手机比例，并提供主题入口。

## 入口页交互反馈（2026-10-23）

入口页示例不再是静态仿控件。提供独立的本地互动体验，可切换排序与话题、展开讨论、点赞收藏、写回复和试发文字；明确标记示例及刷新重置，不调用真实 API 或模拟鉴权。补充校园话题入口、使用介绍和常见问题，形成完整介绍页；保持手机控件比例、深浅主题和键盘可用。

## 信息流反馈：刷新与悬停（2026-10-23）

- 刷新改用小尺寸的细线图标，保持足够点击范围与加载禁用状态。
- 删除旧帖子悬停位移，保持帖子之间分隔线连续，鼠标与键盘操作均不移动正文。
- 明确当前下拉与侧栏是固定常用话题入口，不是自定义标签全集；不在本轮擅自新增动态标签系统。

## 选择菜单与通知细节（2026-10-23）

- 使用统一页面内选择控件，展开后的字号、行高、背景、选中态与深浅主题一致，避免系统原生菜单脱离界面。覆盖首页筛选、发布话题、评论者、主题、活动及邮箱后缀等同类入口。
- 菜单贴近触发控件，在视口内翻转与限制高度；支持点击、方向键、首尾、键入查找、确认、Escape、Tab 和点击外部关闭。弹窗内部菜单的 Escape 只关闭菜单。
- 通知桌面扩大为约 640px 的阅读面板，手机保留视口边距；统一标题、正文、时间、未读及全部已读的视觉比例，长通知及矮屏可读可滚动。
- 核对控件展开状态、焦点、禁用、加载、空态、长内容以及实际截图，不仅检查页面是否溢出。

## 发布入口与页面滚动反馈（2026-10-23）

- 桌面发布入口固定在左栏最下方，账号信息与退出在其上方；矮窗口内导航可独立滚动，不挤掉底部操作。
- 根画布与滚动条显式跟随深浅主题，避免右侧出现异色轨道；保留可用的滚动条。
- 页面保持一个文档滚动区域，首页结尾和入口页完整页脚在滚动到底时可见，手机内容位于固定底栏上方；检查不同高度、缩放与弹窗开关后的状态。

## 按任务复查交互（2026-10-23）

依据 Nielsen 十项启发式和 WCAG 2.2 点击目标要求复查主要用户任务，保留 Treehole Art 的连续阅读与克制控件。草稿箱只是检查起点，不以改一个按钮代替任务流程验收。

- 草稿每行直接提供“继续编辑”和“删除”，手机同样可发现，不依赖悬停或先进入批量模式。单条与批量删除分别确认准确对象；取消不改变数据，失败保留对象并在操作处提供错误反馈、重试；请求中阻止重复操作。
- 草稿列表明确初次加载失败与空态，批量选择有清楚的退出和选择状态；删除后焦点落在合理的剩余内容或空态入口。
- 编辑草稿加载期间不得误写覆盖；保存与发布不得并发提交或覆盖用户保存期间的新输入；发布失败后继续保留离开保护。图标删除等控件必须有准确名称。
- 收藏夹创建、重命名和删除提供一致的反馈与防重复提交；键盘能够打开、关闭并操作管理入口。紧凑个人空间中也能发现新建收藏夹。
- 长自定义收藏夹名称不撑宽页面，操作菜单和删除确认保持在手机视口内；菜单使用明确的三点图标。
- 个人空间往返详情保留当前选项；喜爱和活动列表失败有重试；活动申请关闭后在本页保留输入，发送与图片处理显示状态并防重复；邮箱验证码绑定发送地址，改变地址后可重新获取。
- 评论草稿及发送/图片处理状态跟随讨论在当前会话保留，旧请求不得清空更新的草稿或恢复已切换账号的内容；弹窗等待和失败后的键盘焦点始终可达。
- 检查其余阅读、搜索、讨论、收藏喜爱、公告、设置、登录及入口页的常用动作、状态和失败恢复；将发现、修复与仍存在的验收边界写入课程说明。
- 单元测试覆盖数据保留、失败重试及重复提交；浏览器验证电脑与手机、深浅主题、键盘和触屏以及主要任务回归。

## 快捷发布话题、图片与阅读反馈（2026-10-24，已实现并完成本地验证）

- 首页快捷发布可同时选择常用话题、输入自定义话题，显示可移除的已选话题；处理重复项和中文输入法，不将发布话题与筛选混为一谈。切换完整编辑器保留全部话题及图片。
- 首页明确显示添加图片入口，支持一次或分次选择多图，最多 9 张；保留预览、移除、图片处理状态及失败后的内容。前端检查与后端一致的单图/总量限制，发布中防重复，旧异步操作不得覆盖新的输入或跨账号恢复内容。
- 修正多图在手机变成冗长单列、容器高度不完整传递和单张长图被压成细条等显示问题。单图有稳定预览区域并保留比例；长图提供明确裁切提示并可查看完整内容；多图按 2/3 列紧凑展示，点击可查看全部图片。
- 图片查看器支持关闭、上一张/下一张、索引、放大及触屏，键盘焦点在查看器内并回到打开入口；加载失败显示可理解反馈，不留空白。
- 帖子悬停与键盘聚焦有轻微背景/边框反馈，不产生位移、分隔线重叠或阴影拼接；尊重减少动态偏好和触屏。
- 验证真实文件上传至演示 API、多话题与多图片发布、完整编辑器继承、1/2/3/4/9 图及长宽图片的电脑/手机深浅主题和预览键盘/触屏操作。

验收：42 组图片主题/宽度/数量布局通过，实际文件选择、多话题发布与失败重试、900×6000 长图继承通过；查看器 4 组宽高、键盘焦点恢复、缩略图定位、放大滚动、真实触屏上下文中的点击与滑动均通过。前端 35 文件 / 168 项测试、lint、生产构建通过，细节和验收边界见课程说明。

## 图片入口环境差异（2026-10-24）

- 核对真实点击触发文件选择的流程，不把直接设置 file input 的自动化检查当成系统选择框已验收。
- 内置浏览器在原生 file input 的真实点击后立即派发 cancel，项目代码无法代替宿主打开系统文件面板。首页补充粘贴截图和拖入图片，与文件选择共用数量、大小、处理状态及账号归属保护；普通文字粘贴保留默认行为。
- 图片入口给出可理解的替代操作，取消选择不得清除原有图片或显示上传成功；在内置浏览器验证实际粘贴后的缩略图，在独立浏览器验证点击入口和文件选择。

## 快捷发布工具栏对齐（2026-10-24）
